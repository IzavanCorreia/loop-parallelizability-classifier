# Synthetic loop dataset (ASOC version)

Generated by `code/generator/ga.py`. The genetic algorithm is DEAP: population 10,000, 50 generations, roulette
selection, one-point crossover with probability 0.9, uniform integer mutation with probability 0.1. The genomes
are decoded by `code/generator/loopgen.py`, and every pair is validated by the dynamic dependence oracle in
`code/generator/oracle.py`.

## Files

| File | Content |
|---|---|
| `Parallelizable_codes.py` | 4,000 samples, `Code i:` blocks separated by a line of 40 `=` |
| `Undefined_codes.py` | 4,000 samples; `Code i` here and `Code i` in the other file form the minimal pair `i` |
| `metadata.csv` | pair id, loop family, iteration form, wrapper, data domain, language of identifiers, minimality, token count, oracle reason, genome |
| `ga_log.csv` | per-generation statistics of the evolutionary run |
| `generator_config.json` | parameters of the run |

## Design

- **One target loop per sample**, 5–25 lines. Every sample stays under 256 DistilBERT tokens.
- **Minimal pairs:** both variants share names, data literals, iteration form, expressions and distractor
  statements. They differ only in the statement that decides whether a value flows between iterations. The
  identifier sets of the two variants are identical; this is enforced in the fitness.
- **Labels:**
  - **Parallelizable:** no value flows between iterations. Private temporaries, writes to positions exclusive to
    the iteration, and the *map* pattern (`append` to an output list that is not read in the loop) are allowed.
  - **Undefined:** accumulators and reductions, recurrences, reads of positions written by other iterations,
    indirect writes, early exits, and state shared between iterations.
- **Families:** nine minimal-pair patterns (A–I), listed in the docstring of `loopgen.py`.
- **Oracle:** each variant is executed iteration by iteration with instrumented lists, dicts, sets and names.
  The label must match the construction label, otherwise the genome gets fitness 0.01 and never enters the
  dataset.
